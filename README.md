# Kenyan Cities REST API

## Overview

The **Kenyan Cities REST API** is a backend development project built with **Node.js** and **Express.js**.

The project was created to practise the core concepts of backend development, including:

- Creating an Express server
- Building REST API endpoints
- Using HTTP methods
- Working with query parameters
- Working with route parameters
- Handling JSON request bodies
- Validating user input
- Returning appropriate HTTP status codes
- Performing CRUD operations
- Handling errors
- Testing API endpoints with cURL

The application manages a list of Kenyan cities stored temporarily in memory.

---

## Project Objectives

The main objectives of this project are to:

- Understand the fundamentals of backend development.
- Learn how Node.js is used to run JavaScript on the server.
- Create a backend server using Express.js.
- Build REST API routes from scratch.
- Practise using `GET`, `POST`, `PATCH`, and `DELETE` HTTP methods.
- Work with query parameters for filtering data.
- Work with URL parameters for identifying specific resources.
- Handle JSON request bodies using Express middleware.
- Validate incoming data before storing it.
- Generate unique IDs for newly created resources.
- Return appropriate HTTP response status codes.
- Handle missing resources using `404` responses.
- Perform basic CRUD operations.
- Understand the difference between `req.query`, `req.params`, and `req.body`.
- Test backend API endpoints using the terminal and cURL.
